# Perler Beads 拼豆工坊

一个基于 **Three.js** 的 3D 拼豆（Perler Beads）小游戏，在浏览器里体验真实的拼豆乐趣：放豆、擦除、取色、导入图片自动转图案、导出图纸。

## ✨ 功能特性

- 🥢 **3D 夹子光标**：鼠标就是一把金属镊子，真实夹着一颗拼豆；按下时夹子下压、松手回弹，移动带惯性倾斜
- 🔊 **合成音效**：豆子落下"哒"一声（WebAudio 合成，高频 tick + 低频闷响），擦除有"啵"声，🔊 按钮可静音
- 🫳 **落豆物理**：豆子从夹子尖掉落，重力加速 + 落地压扁回弹动画
- 🎨 **3D 拼豆画板**：钉柱画板 + 圆豆 + 中孔效果，InstancedMesh 渲染，万级豆子流畅运行
- 🧩 **9 个内置模板**：Claude 标志、Claude 小精灵、爱心、星星、太空侵略者、蘑菇、彩虹、小幽灵、花朵
- 🖌️ **三种工具**：放豆（拖动连画不断线）、擦除、取色器
- 🌈 **20 种经典拼豆颜色**（含 Claude 珊瑚橙）
- 🖼️ **图片导入**：任意图片自动降采样并映射到最接近的拼豆颜色，按图片比例自动调整画板
- 📸 **导出 PNG**：像素风拼豆图纸（含中孔）
- 💾 **实时自动保存**：每次放豆/擦除自动存到浏览器，刷新页面自动恢复
- 🪵 **木桌环境**：程序化木纹桌面 + 一支铅笔，中键旋转视角

## 🚀 运行

```bash
npm install
npm run dev        # 开发模式
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```

## 🎮 操作说明

| 操作 | 效果 |
|------|------|
| 左键点击 / 拖动 | 夹子放豆（哒！） |
| 右键点击 / 拖动 | 擦除（啵） |
| 鼠标中键拖动 | 旋转视角 |
| 滚轮 | 缩放 |
| 💉 取色工具 | 点击已有豆子吸取颜色 |

## 🛠️ 技术

- [Three.js](https://threejs.org/) + [Vite](https://vite.dev/)
- `InstancedMesh` 批量渲染豆子与钉柱
- 射线与平面求交实现网格拾取，Bresenham 插值实现拖动连画
- Canvas 2D 实现图片降采样与最近色映射、PNG 导出
